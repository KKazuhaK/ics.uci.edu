Paste Designs · Demo

下面是为 md-viewer 上传区设计的 5 种「粘贴 Markdown」交互方案。点 tab 切换，每个方案都能真实交互（拖文件 / 选文件 / 粘贴文本都会触发）。

★ Combined · 落地预览 — 简化版：只保留 F 按钮（一键）+ D 全页 ⌘V（兜底）。砍掉 textarea — 想编辑去 md-editor 即可。

Select, drag, or paste a Markdown document to render it here.

or hit ⌘V / Ctrl+V anywhere on the page
交互说明
  • 📄 拖文件 / 点击选文件 — 原有路径，不变
  • 📋 Paste from clipboard 按钮 — 一键调 navigator.clipboard.readText()，首次弹权限框
  • ⌘V / Ctrl+V — 页面任意位置粘贴，自动渲染（无权限框）
  • 读不到剪贴板（不支持 / 拒绝权限）时，按钮自动提示用 ⌘V

A · Tabbed switch — 两段切换：上传文件 / 粘贴文本。最显式，UI 信号最强。

+ 模式分离，状态清晰；新用户一眼看懂
− 多一次点击；占垂直空间；切换会丢未提交内容（除非保留）

B · Unified zone — 单一框，支持拖入 / 点击选 / 点击编辑直接粘贴。空间最省，affordance 最少。

+ UI 紧凑；一个区域承担所有输入；状态自然过渡
− 点击行为有歧义（选文件 vs 进入编辑）；要明确分隔交互区

C · Stacked split — 拖拽区在上，分隔线 OR，下方常驻 textarea。两条路径同时可见。

+ 零额外操作；两种入口同时暴露；学习成本最低
− 占垂直空间最大；视觉上稍重
OR PASTE TEXT

D · Global paste — 拖拽框不动，整页监听 ⌘V / Ctrl+V，粘贴纯文本就直接渲染。最少改动 UI。

+ UI 完全不改；最快路径；"power user" 最爽
− 不可见的功能（discoverability 差），需要 hint 文案
提示：在本卡片任意位置按 ⌘V / Ctrl+V 直接粘贴 Markdown。

E · Inline expand — 拖拽框默认展示，下方一个折叠链接「Or paste markdown text」展开 textarea。轻、收敛、可发现。

+ 默认 UI 干净；功能可见但不抢眼；进阶用户可选
− 多一次点击；展开动效要顺滑才不显廉价

F · Clipboard button — 拖拽框旁加一个「Paste from clipboard」按钮，点一下用 navigator.clipboard.readText() 直接读剪贴板并渲染。一键到位，最少操作。

+ 一次点击完成；UI 增加最小；语义最直白
− 首次会触发浏览器权限弹窗；iOS Safari 历史上对 readText 限制多；无预览
需要剪贴板权限，首次点击会弹窗确认

💡 我的推荐组合（更新版）：F + D + E — F 按钮放在拖拽区下面（一键路径），D 全页 ⌘V 兜底（power user），E 折叠 textarea 留作可控编辑（粘贴后想改）。三者互补不冲突。如果只能选一个：F 最干脆。
