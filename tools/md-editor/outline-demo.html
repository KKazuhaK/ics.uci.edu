Outline Designs · Demo

三种 Outline 范式直接给你点 —— 同一份样例笔记（10 个标题），每个 Tab 是一种交互方式。点击 / 按快捷键试试感觉。

A · 右侧常驻面板（Typora/Obsidian 范式） — Toolbar 的 📑 Outline 按钮切换显示，状态记到 localStorage。点标题跳转，标题自动高亮。

+ 始终可见全局结构；零额外操作；最直观；最像 Typora/Obsidian
− 占编辑区水平空间；side-by-side 模式下三栏会挤
Outline

B · Toolbar 弹出层 — 同一个 📑 按钮，但点击后弹一个 280px 浮层（不挤主区），点外部或再点按钮关闭。

+ 不占布局；按需出现；视觉干净；和搜索栏类似的浮层范式
− 浮层会盖住右侧内容；要点击/关闭两次操作
Outline

C · Goto-symbol 命令面板（VS Code 范式） — 按 Ctrl/Cmd+Shift+O（或点 toolbar 按钮）弹出居中搜索 + 列表，输入字符模糊筛选，↑↓ + Enter 跳转，Esc 关闭。

+ 0 持久 UI；最快路径；筛选很爽；最 power-user
− 鼠标用户不易发现（需 toolbar 兜底）；必须记快捷键

💡 推荐：A + C 组合 —— 鼠标党有 A（Typora 范式，常驻可切换），键盘党有 C（VS Code 范式，Ctrl+Shift+O 闪电跳转），同一份数据。B 单独有点鸡肋（功能上是 A 的"按需"版，但失去常驻好处）。
