CS 121

CS 121 / IN4MATX 141 is UCI's information retrieval course: how search engines collect, process, index, and rank web documents.

This page collects week-by-week notes for classmates who want a structured review of text processing, the web graph, SEO and spam, web crawling, the ethics and law around collecting web data, and text processing and term-document matrices.

CS 121 / IN4MATX 141 是 UCI 的信息检索课程,讲搜索引擎如何收集、处理、索引网页文档并为其排序。

这个页面汇总按周整理的课程笔记,方便同学回顾文本处理、网络图、SEO 与垃圾信息、网络爬虫、采集网页数据涉及的伦理与法律问题,以及文本处理与词项-文档矩阵。
