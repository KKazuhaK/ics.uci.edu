IN4MATX 43

IN4MATX 43 introduces software engineering through the people, processes, and tools behind real-world software systems.

These notes are organized week by week so classmates can review core ideas such as requirements, architecture, testing, collaboration, and software quality.

IN4MATX 43 主要介绍软件工程,关注真实软件系统背后的人、流程与工具如何协同工作。

这些笔记按周整理,方便同学回顾需求、架构、测试、协作方式和软件质量等核心主题。
