IN4MATX 133

IN4MATX 133 is UCI's User Interface Software course, focused on building interfaces with web technologies: HTML, CSS, JavaScript, TypeScript, and modern UI frameworks.

This page collects lecture-by-lecture notes with live, editable HTML/CSS/JS demos, for classmates who want a structured review of markup and accessibility, styling and responsive layout, the DOM, and UI tooling.

IN4MATX 133 是 UCI 的用户界面软件课程,重点在于用 Web 技术构建界面:HTML、CSS、JavaScript、TypeScript 以及现代 UI 框架。

这个页面汇总按讲整理的课程笔记(目前为英文版),配有可编辑的 HTML/CSS/JS 实时演示,方便同学回顾标记与无障碍、样式与响应式布局、DOM,以及各类 UI 工具。
